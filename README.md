# 26mspm0-car

MSPM0G3507 电赛小车工程，按功能演进整理的版本历史。

每个 tag 对应一个开发阶段，`git checkout v06` 即可回到「加入 5 路循迹」时的状态。

| 标签 | 功能 | 日期 | 文件数 |
|---|---|---|---|
| `v01` | 速度闭环（无 RTOS） | 2026-07-27 | 46 |
| `v02` | 接入 MPU6050 姿态传感器 | 2026-07-28 | 46 |
| `v03` | 加入 TB6612 电机驱动 | 2026-07-28 | 46 |
| `v04` | 加入 yaw 角度闭环 | 2026-07-28 | 46 |
| `v05` | 加入 4 个按键输入 | 2026-07-28 | 46 |
| `v06` | 加入 5 路灰度循迹 | 2026-07-28 | 48 |
| `v07` | 灰度循迹调试与参数优化 | 2026-07-29 | 50 |
| `v08` | 扩展为 8 路灰度，16 秒完成一圈 | 2026-07-29 | 50 |
| `v09` | 修复 OLED 显示报错 | 2026-07-30 | 52 |
| `v10` | 整理电机控制与循迹逻辑 | 2026-07-30 | 54 |
| `v11` | 加入编码器测速闭环 | 2026-07-30 | 52 |
| `v12` | 编码器版 8 路循迹 | 2026-07-31 | 52 |

## 使用

```powershell
git clone git@github.com:hjc180926/26mspm0-car.git
git log --oneline --decorate
git checkout v08      # 查看 8 路灰度版本
git diff v07 v08      # 对比两个版本
```

## 目录

- `keil/`：Keil uVision 工程与源码
- `Component/`：电机、灰度、OLED、MPU6050 等驱动
- `main.c` / `ti_msp_dl_config.*`：主程序与 SysConfig 生成代码
- `k230-ball-balance/`：钢球平衡的 K230 视觉 + MG996R 舵机 PID（MicroPython，独立系统）

> 说明：`docs/` 下的芯片手册 PDF 未纳入仓库，避免仓库体积过大。
>
> `v01`–`v12` 标签记录的是 MSPM0 底盘的演进；`k230-ball-balance/` 是后加入的平衡机构代码，不参与该版本序列。
